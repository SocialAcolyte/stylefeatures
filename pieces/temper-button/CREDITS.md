## From the README

- The engine: temper-run, by Claude Code (`claude-2026-10-27 (set aside)/potential/temper-run`), copied unchanged. Its README has the physics in full.
- Optical data: iron, Johnson and Christy, *Phys. Rev. B* 9, 5056 (1974); magnetite (Fe3O4), Querry, CRDC-CR-85034 (1985). Both via refractiveindex.info.
- CIE 1931 2° colour-matching functions from CVRL (cvrl.org); the D65 illuminant from CIE 15.
- No images. The original demo's engraving (Asher B. Durand's banknote smith, The Met, CC0) is not used, so it isn't shipped and there is no `assets/` folder.
